# AGENTS.md

First Aid is a personal, self-hosted tool for planning a healthcare year and keeping lightweight records of visits, documents, benefits, claims, and future care.

Read these before making product or domain decisions:

- [docs/PRODUCT.md](./docs/PRODUCT.md)
- [docs/DOMAIN.md](./docs/DOMAIN.md)
- [docs/ROADMAP.md](./docs/ROADMAP.md)

## Working on a roadmap phase

Before implementing a new phase or substantial feature, first have a conversation with the user to understand the actual problem and the smallest usable workflow needed now.

Keep the user focused on making First Aid useful right away rather than designing a complete healthcare product.

Prefer solving the personal problem first. Do not add complexity only because medical, insurance, or EMR products commonly have it.

When real usage exposes a missing concept, update the domain and roadmap as needed.

## Privacy in the open repository

This repository is open.

Personal names, medical details, provider information, insurance information, documents, or other private context may be supplied during development to explain a problem.

Never copy identifying personal information into source code, examples, fixtures, tests, documentation, commit messages, or other repository content.

Use generic or fictional examples instead.
